# FitterSketch Private Field Beta — 0.9.0 (Build 3)

This is the current Android beta build of FitterSketch for field testing.

## Download

Under **Assets**, download:

`FitterSketch-0.9.0-build3.apk`

## What’s new in Build 3

- Added a short **Getting Started** guide for new users.
- The guide appears automatically the first time FitterSketch is opened after this update.
- New users can **Skip** the guide or move through it with **Next** and **Done**.
- Once dismissed or completed, the guide stays out of the way on later launches.
- Added **Settings → Getting Started** so the guide can be reopened at any time.
- Existing Quick Sketch, project, PDF, Inspect, Document, export, and feedback workflows remain available.
- FitterSketch continues to use the permanent Android package identity `com.fittersketch.app` and the same signing key so this APK can install as an update over Build 2.

## Install / update

1. Download `FitterSketch-0.9.0-build3.apk` from **Assets** below.
2. Open the downloaded APK.
3. If Android asks, allow **Install unknown apps** for the browser or file manager you used.
4. Install FitterSketch.

If Build 2 is already installed, Android should update it in place and retain the app's local data because the package identity and signing key are unchanged.

## Beta notes

- FitterSketch is still beta software.
- Keep exported copies of important project information.
- Do not rely on a beta build as the only copy of critical job information.
- Only install APK files published from this official FitterSketch Releases repository.
