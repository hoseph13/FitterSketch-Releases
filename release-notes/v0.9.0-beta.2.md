# FitterSketch Private Field Beta — 0.9.0 (Build 2)

This is the current Android beta build of FitterSketch for field testing.

## Download

Under **Assets**, download:

`FitterSketch-0.9.0-build2.apk`

## What’s in this build

- Permanent **FitterSketch** app name, branding, and launcher icon.
- Android package identity established as `com.fittersketch.app` for future beta updates.
- Home and Settings screens updated for the FitterSketch beta.
- **Settings → Send feedback** is available for reporting issues and suggesting improvements.
- Core field-sketch workflow remains available, including pipe drawing, project save/open, PDF import/background use, Inspect/Document workflows, and PDF preview/export.
- This build uses the permanent Android signing key so future FitterSketch beta APKs can install as updates when package/signing requirements remain unchanged.

## Install / update

1. Download `FitterSketch-0.9.0-build2.apk` from **Assets** below.
2. Open the downloaded APK.
3. If Android asks, allow **Install unknown apps** for the browser or file manager you used.
4. Install FitterSketch.

Future FitterSketch builds signed with the same key and package identity should install as updates over this build and retain local app data.

## Beta notes

- FitterSketch is still beta software.
- Keep exported copies of important project information.
- Do not rely on a beta build as the only copy of critical job information.
- Only install APK files published from this official FitterSketch Releases repository.
