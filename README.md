# FitterSketch

**Field piping sketches without the drafting-table overhead.**

FitterSketch is an Android app being developed for pipefitters and other field users who need to make quick, readable piping sketches, work over PDF backgrounds, inspect piping layouts, and create documentation from the field.

> **Beta software:** FitterSketch is currently in private field beta. Expect changes as testing continues. Please do not rely on a beta build as the only copy of critical project information.

## Download the latest Android beta

**[Download the latest FitterSketch release](https://github.com/hoseph13/FitterSketch-Releases/releases/latest)**

That link always points to the newest published beta release. It is also the permanent address used by the FitterSketch QR code, so the QR code does not need to change when a newer build is published.

On the release page, open **Assets** and download the `.apk` file.

## Install on Android

1. Download the FitterSketch `.apk` from the latest release.
2. Open the downloaded file on your Android phone or tablet.
3. Android may ask for permission to **Install unknown apps** from the browser or file manager you used. Allow it for that app when prompted.
4. Confirm the installation.
5. Open **FitterSketch** from your app launcher.

FitterSketch is not currently distributed through Google Play, so Android may display additional warnings. Only install APK files downloaded from this official FitterSketch Releases repository.

## Updating FitterSketch

When a new beta is published:

1. Return to the **latest release** link above.
2. Download the new APK.
3. Install it over your existing FitterSketch installation.

As long as the package is signed with the same FitterSketch signing key, Android will treat it as an update and keep the app's local data. Before installing beta updates, keeping copies of important exported files is still recommended.

## Quick overview

FitterSketch is designed around a field-first workflow:

- Start a **Quick Sketch** or create a saved project.
- Draw single-line piping on an isometric workspace.
- Add fittings and inline components where they belong in the run.
- Import a **PDF** and sketch over the drawing when needed.
- Move between **Sketch**, **Inspect**, and **Document** workflows while keeping drawing context.
- Save projects locally and create documentation/PDF output for sharing.

The interface and feature set are still evolving during beta testing.
